# Security Policy

Do not open a public issue for credentials, private identifiers, restricted competition material, or a vulnerability that could expose another person or system.

Report sensitive findings privately to the organization contact email shown in the OpenKaggle GitHub profile. Include the affected repository, a concise impact description, reproduction details, and any suggested mitigation. Please avoid accessing or copying more data than is necessary to demonstrate the issue.

Historical research repositories may be archived and unsupported. Their README should state maintenance status and known runtime limits.
