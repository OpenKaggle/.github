# Getting Help

For project-specific questions, start with that repository's README, open issues, and documented status.

Use the smallest public route that fits the work:

| Route | Use it for |
| --- | --- |
| Bug issue | A reproducible code, documentation, or published-workflow problem |
| Reproduction issue | What matched, differed, or failed when rerunning a cited release |
| Provenance issue | A source, license, attribution, or data-boundary correction |
| Proposal issue | A new repository, experiment, analysis system, or external project |
| Correction/withdrawal issue | A safe public request to replace, restrict, or withdraw a published item |
| Discussion | Exploratory questions, cross-project ideas, or contributor conversation |
| Private contact | Credentials, personal data, restricted material, security, or legal concerns |

Never put sensitive evidence into a public issue. Use the private organization
contact for security, privacy, or restricted-data concerns and describe only
the minimum needed to locate the material.

Please include the repository, revision, command or notebook entry point, environment, expected result, actual result, and any relevant receipt. Archived projects may receive documentation or provenance help without active implementation support.
