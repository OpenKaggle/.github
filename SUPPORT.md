# Getting Help

For project-specific questions, start with that repository's README, open issues, and documented status.

- Use an issue for a reproducible bug, documentation gap, provenance correction, or focused research question.
- Use a discussion when the question is exploratory, cross-project, or about contributing a repository.
- Use the private organization contact for security, privacy, or restricted-data concerns.

Please include the repository, revision, command or notebook entry point, environment, expected result, actual result, and any relevant receipt. Archived projects may receive documentation or provenance help without active implementation support.
